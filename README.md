# Royal City

Royal City is an intelligent living infrastructure that connects people, communities, and the physical and economic world around them through one unified identity and ecosystem.

> **One identity. One connected ecosystem. Any authorized action.**

## Repository purpose

This repository is being established from the domain outward. The first stage defines what Royal City is, what concepts exist, how they relate, and what remains an open question. Implementation follows the domain and architecture rather than inventing requirements ahead of them.

## Foundational chain

`Identity → Relationships → Authorization → Action → Result → Unified Ecosystem`

## Development stages

1. **Stage 1 — World & Domain Model**
2. **Stage 2 — Digital Ecosystem Architecture**
3. Implementation design
4. Foundation / repository engineering
5. First vertical slice
6. Applications and integration
7. Testing and validation
8. Staging and production
9. Operations and evolution

## Repository rule

References to other projects are used only for mature structure, documentation discipline, and engineering practice. Their product domains, features, or requirements are not treated as Royal City requirements.
