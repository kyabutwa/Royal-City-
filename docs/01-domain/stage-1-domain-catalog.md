# Royal City — Stage 1 Domain Catalog

## Purpose

This catalog is the current canonical inventory of domain concepts.

## Established core

| Concept | Status | Meaning |
|---|---|---|
| Actor | Established | Participant capable of domain participation |
| Identity | Established | Unified representation through which an actor participates |
| Relationship | Established | Meaningful connection providing domain context |
| Authority | Established | Basis for exercising a power, responsibility, or control |
| Authorization | Established | Decision permitting or denying an action |
| Action | Established | Meaningful operation performed by an actor |
| Place | Established | Recognized physical/spatial domain |
| Resource | Established | Something that can be acted upon, controlled, accessed, allocated, or used |
| Service | Established | Capability made available to participants |
| Transaction | Established | Economic exchange/commitment where transactional semantics apply |
| Community | Established | Participating social/organizational context |
| State | Established | Current domain condition |
| Record | Established | Required persistent representation of a significant domain occurrence |

## Concepts requiring refinement

The following are not yet separate canonical concepts:

- role
- membership
- ownership
- control
- responsibility
- representation
- delegation
- facility
- building
- unit
- infrastructure
- asset
- request
- obligation
- event
- policy
- rule
- settlement
- dispute
- entitlement

They remain candidate concepts until the remaining Stage 1 decisions establish their exact semantics.

## Canonical distinction

The domain must preserve:

`Actor → Identity → Relationship / Authority → Authorization → Action → Target → Result → State / Record`

This is the current backbone of the model.
