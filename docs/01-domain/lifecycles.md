# Domain Lifecycles

## Purpose

This document defines the lifecycle questions that must be answered for major Royal City concepts.

No lifecycle is considered final until the domain establishes its states and transition rules.

## Identity lifecycle

Questions:

- How is an identity established?
- Can an identity be suspended?
- Can it be revoked?
- Can it be recovered?
- What survives identity suspension or replacement?
- Can one actor have multiple identities or identity contexts?

## Relationship lifecycle

Questions:

- How is a relationship established?
- Who can establish it?
- Can it be delegated?
- Can it expire?
- Can it be revoked?
- What happens to actions authorized through it?

## Authorization lifecycle

Questions:

- How is authorization granted?
- What makes it active?
- Can it be conditional?
- Can it expire?
- Can it be revoked?
- How are previously authorized actions treated after revocation?

## Place / resource lifecycle

Questions:

- How is a place or resource introduced?
- Who controls it?
- When is it available?
- Can it be restricted?
- Can control change?
- What happens when it is retired or removed?

## Service lifecycle

Questions:

- Who provides a service?
- How is availability represented?
- How is a service requested?
- When is a request accepted?
- What constitutes completion?
- What happens when the service fails?

## Action lifecycle

Questions:

- What makes an action valid?
- When is it requested?
- When is it authorized?
- When does it begin?
- When does it complete?
- Can it be cancelled?
- Can it be reversed?
- What constitutes failure?

## Transaction lifecycle

Questions:

- When does an economic transaction exist?
- When is it committed?
- Can it be disputed?
- Can it be reversed or refunded?
- What records are authoritative?

## Community lifecycle

Questions:

- How is a community formed?
- How does participation begin?
- Who has authority?
- How can rules change?
- How can a community dissolve or merge?
