# Domain Overview

Royal City will be modeled as a connected living domain rather than as a collection of unrelated applications.

The current foundational chain is:

`Identity → Relationships → Authorization → Things → Actions → Transactions → State → Ecosystem`

The domain model will establish what each concept means, what relationships exist between them, which rules govern them, and which questions remain unresolved.

## Domain areas to establish

- People
- Identity and roles
- Property and assets
- Services
- Operations
- Community
- Requests and work
- Resources and access
- Money and commerce
- Communication and information
- Security and safety
- Governance
- Workflows
- Domain relationships
- Domain state
- Domain rules

No implementation model is implied by this document.
