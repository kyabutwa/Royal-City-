# Digital Ecosystem

This directory contains the Stage 2 ecosystem-architecture foundation.

Detailed architecture will follow the completed domain model rather than being invented in advance.


## Cross-repository reconciliation

The Stage 2A migration and reconciliation package is maintained in [migration/](./migration/). It records the inventory, canonical concept mapping, conflict register, reconciled target architecture, and staged implementation migration plan for LEGAX and LegaKeys into Royal City.

Migration documents are architectural records; they do not by themselves claim that inherited implementation is production-ready.
